# 06 · 经典实验与争论：纳米膜上的卡西米尔力与原位表面电势测量

收录日期：2026-10-28　|　来源：arXiv 开放获取（未使用任何第三方镜像）

## 一、为什么收录这三条

这一组文献不属于罗鹏顺组，也不属于华科，但它正好补上本集的两块拼图：

1. **"原位表面电势测量"是 patch 控制的正面案例。**
   本集 D1（秦莉兰）用"PREP 腔原位镀膜、样品不进大气"来抑制 patch；R07（UC Riverside）用"原位 UV + Ar⁺ 清洗"把残余电势压掉一个数量级。这篇 2012 PRL 则把**表面电势的原位测量直接做进了卡西米尔力装置**——同一方法学谱系的第三种实现。
2. **它是一场公开学术争论的主角。**
   该文发表后，Casimir 理论界的三位核心人物（Bordag、Klimchitskaya、Mostepanenko）在同期 PRL 发表 Comment 质疑；随后原作者又发了 **Erratum**。对理解"实验数据如何与 Lifshitz 理论比较"而言，这比任何综述都具体。

## 三、与本集其他文献的关系

- **D1**（秦莉兰 2015）：同样强调"表面制备决定测量上限"，用真空内镀膜抑制 patch；
- **R07**（Dhital & Mohideen 2024）：用原位 UV/Ar⁺ 清洗，并把"V₀ 是否随间距变化"作为判据；
- **B-04**（邵成刚组 2006）：重推 Lifshitz 公式并讨论**倏逝模**——Comment 中争论的理论细节正落在这里；
- **R12 第 5.3 节**：把"Plasma 还是 Drude"作为核心问题陈述——这场争论是它的一个具体战场。
