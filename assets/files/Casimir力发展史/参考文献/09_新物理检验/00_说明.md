## 二、N01 · Ma, Takhistov & Iizuka 2026

| | |
|---|---|
| **标题** | *Casimir Geometry as a Probe of Short Range Forces* |
| **作者** | Xiaolin Ma, Volodymyr Takhistov, Hideo Iizuka |
| **预印本** | **arXiv:2603.22413**（2026） |
| **报告号** | KEK-QUP-2026-0005、KEK-TH-2819 |
| **页数** | 11 |

**核心思想**（据摘要）：短程新物理（额外空间维度、新轻玻色子）会在亚微米尺度上表现为对牛顿引力的偏离。**卡西米尔力的几何依赖**（球—板、板—板、柱—板……）可以作为一种"探针"，把这类偏离从背景中分离出来。

**为什么值得收**：这是把"几何"本身当成变量——不同几何下卡西米尔力的标度不同，而新物理的贡献可能不随几何同样变化。**用"差"来消掉已知物理**，正是 N02 那篇的方法。

## 三、N02 · 2017 年轴子约束

| | |
|---|---|
| **标题** | *Constraints on axion-like particles and non-Newtonian gravity from measuring the difference of Casimir forces* |
| **预印本** | **arXiv:1704.05892**（2017） |
| **页数** | 16 |

**核心思想**：不测单个卡西米尔力，而是测**两种几何（或两种材料）下卡西米尔力之差**。已知的卡西米尔贡献在"差"中部分抵消，剩下的偏差就可以用来约束**轴子类粒子**与**非牛顿引力**。

**方法学意义**：这是"系统误差相消"的标准范式——**当信号太弱时，不要测绝对值，测差值。**
