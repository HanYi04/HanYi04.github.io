SECTION 01误差传播框架

七项独立误差按方差合成。每一项都给出公式与参数来源，便于逐行复核。

(δP/P)tot = √[ (①)stat² + (②)sp² + (③)patch² + (④)PFA² + (⑤)rough² + (⑥)ball² + (⑦)cal² ] (1)
为什么不用"1/z"而用"π³ℏcR/360z³"

球—板 Casimir 力由 PFA 给出：FC = 2πR·Ec(z)，而 Ec = π²ℏc/(720z³)。合并即 FC = π³ℏcR/(360z³)。在 20 nm、R=150 μm 时给出 51 nN，在 100 nm 时 0.41 nN，与文献量级一致（本文为理想导体基准，真实金属按 Lifshitz 修正后绝对值有差，但误差项的相对结构不变）。

SECTION 02方案 A：微米窗口（R=150 μm，0.4–1.25 μm）

2.1 逐项代入（以 z = 0.5 μm 为例）

① 统计项

FC = π³ℏcR/(360z³) = 31.006×3.16×10−26×1.5×10−4 / (360×(5×10−7)³) = 3.27 pN
δF/√T = 0.3 pN/√100 = 0.03 pN　⇒　① = 0.03/3.27 = 0.92%

② 间距项

② = 4×0.51 nm / 500 nm = 0.41%

③ patch 项

δV = z·δF/(2π²ε0RVAC) = 5×10−7×3×10−13 / (19.74×8.854×10−12×1.5×10−4×0.2) = 28.6 μV
占比 = 1.022×1016×(0.0116)²×(5×10−7)² = 34.4%　⇒　残差 = 2×1.022×1016×0.0116×2.86×10−5×(5×10−7)² = 0.17%

注意：patch 力占 34%，但扣掉之后只剩 0.17%——这就是"可测即可扣"的量化含义。

④–⑦

  • ④ PFA = 0.4×500/150000 = 0.13%
  • ⑤ 粗糙度 = 3%×(1/2.37)²×(20/500)² = 0.0013%，残差取 40% → 0.0005%（微米尺度可忽略）
  • ⑥ 球半径 = 0.93/259.7（SEM 直径误差 / 直径）= 0.5%
  • ⑦ 标定 = 1%（保守）

合成

√(0.92² + 0.41² + 0.17² + 0.13² + 0.0005² + 0.5² + 1²) = √2.31 = 1.52%

2.2 全窗口逐点结果

方案 A 的优化杠杆
  • 延长积分：统计项 ∝ 1/√T。T 从 100 s 到 1000 s，统计项降 3.2 倍。
  • 改进标定：1% 的标定项在甜点区已成为第二大项，需把 VAC 与 HF-V 做到 0.3% 才能让总误差进 1%。
  • 球径测量：0.5% 已接近 SEM 极限，可改用光学谐振/多角度拟合。

SECTION 03方案 B：纳米窗口（R=10 μm，20–100 nm）

3.1 逐项代入（以 z = 20 nm、δd₀ = 0.5 nm 为例）

① 统计项

FC = π³ℏcR/(360z³) = 31.006×3.16×10−26×1×10−5 / (360×(2×10−8)³) = 3.4 nN
① = (0.3 pN/√10) / 3.4 nN = 0.003%　（完全可忽略）

② 间距项 —— 主项

② = 4×0.5 nm / 20 nm = 10.0%

③ patch 项

δV = 2×10−8×3×10−13 / (19.74×8.854×10−12×1×10−5×0.2) = 17.2 μV
占比 = 1.022×1016×(0.0116)²×(2×10−8)² = 0.055%　⇒　残差 = 0.00016%

在 20 nm 处 patch 占比只有 0.055%（因为 ∝z²），但若 CPD 未补偿到 mV 级（0.41 V），占比会跳到约 69%——所以"先补偿再测"是硬前提。

④–⑦

  • ④ PFA = 0.4×20/10000 = 0.08%
  • ⑤ 粗糙度 = 3%×(1/2.37)²×(20/20)² = 0.53%，残差 40% → 0.21%
  • ⑥ 球半径 = 0.2/10（SEM 误差 / 直径）= 2.0% ← 第二大项
  • ⑦ 标定 = 1%

合成

√(0.003² + 10² + 0.0002² + 0.08² + 0.21² + 2² + 1²) = √109 = 10.25%

SECTION 05两方案对比与优化杠杆

5.1 两个反直觉结论

  1. 方案 A 的窗口要比"0.4–1 μm"再往下收。1 μm 处统计项已占 7.35%（FC∝1/z³），真正的甜点是 0.4–0.5 μm；1 μm 属于"可做但慢"（需 1.5 h/点）。
  2. 方案 B 不该硬上 20 nm。若绝对间距只能定到 0.5 nm，20 nm 处误差 10%，反而不如 50–100 nm 的 2.3–4.6%；而 100 nm 处模型差异仍有约 12%，判别力 5σ，已经够用。

SECTION 06公式与常数附录

A. 基本关系

  • 理想导体平板压强：P = −π²ℏc/(240d⁴)，能量密度 E = π²ℏc/(720d³)
  • 球—板（PFA）：FC = 2πR·E = π³ℏcR/(360z³)
  • 间距敏感度：δP/P = 4δd/d
  • patch/Casimir 比：ε0V²z²/(2×(π²ℏc/720)) ≈ 1.022×10¹⁶·V²z²
  • KPFM 电势噪声：δV = z·δF/(2π²ε0RVAC)
  • 热噪声极限：δF = √(2k0kBT/(πf0Q))

关于本文。这是"卡西米尔力测量精度分析"的配套计算附录，聚焦两套 MEMS-KPFM 方案的误差预算。物理模型与文献值来自：E1（Garcia-Sanchez 等, PRL 109, 027202, 2012）、D1（秦莉兰, 华中科技大学硕士论文, 2015）、臧凌晨（2025）、赵海燕（2026）、A1-05（Shi 等, PRD 110, 122007, 2024）、D3/D4（曹前进 2017、雷祥洲 2019）。

关于计算。所有"本文计算"的数字均可在第 01 节的公式与附录 C 的参数下复算；计算器与正文使用同一套公式。理想导体基准与真实金属 Lifshitz 修正的差别只影响绝对值，不影响误差项的相对结构。

关于边界。七项之外还有三项未计入：模型差异（5–44%，单列为判别力）、温度对热 Casimir 项的影响（1–2 μm 处约 10%，但对温度不敏感）、以及 patch 空间分布模型的不确定度（Vrms 是否随 z 变化）。它们是"理论不确定度"，与实验误差分开管理。
